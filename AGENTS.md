# Local Repository Memory (`ssysm/OvenMediaEngine`)

This repository is the `ssysm` fork of `OvenMediaLabs/OvenMediaEngine`.

## Fork Changelog Policy

Whenever you add, fix, or modify anything on top of upstream OvenMediaEngine code (including features, bug fixes, build/compatibility fixes, configuration changes, CI workflows, or fork-specific docs), you **must** update `CHANGELOG.ssysm.md` at the repository root to document what was changed:

- Group entries by date (`YYYY-MM-DD`, newest first) under `Added`, `Changed`, or `Fixed`.
- Briefly describe what changed, any new/changed config XML elements, API endpoints, or behavioral notes, and key affected files (and commit hash if already committed).
- Do not add entries for clean upstream merges from `OvenMediaLabs/OvenMediaEngine` unless fork-specific conflict resolutions or adjustments were required.
